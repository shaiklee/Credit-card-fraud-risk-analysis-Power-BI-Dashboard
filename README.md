📌 Project Overview

This project presents an interactive Power BI dashboard designed to analyze and monitor credit card fraud risks across different transaction categories, fraud types, risk levels, states, and time periods.
The dashboard helps stakeholders identify high-risk patterns, understand fraud distribution, and support data-driven fraud prevention strategies.

🎯 Objectives

Analyze fraudulent transactions across multiple dimensions

Identify high-risk fraud types and regions

Monitor fraud trends over time

Support risk-based decision-making for financial institutions
